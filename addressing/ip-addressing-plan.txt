# Multi-Site Enterprise Network — IP Addressing Plan

## 1. Overview

This document describes the IPv4 addressing scheme for the headquarters (HQ), branch office, and simulated ISP network.

The design uses separate /24 subnets for LANs and /30 subnets for point-to-point WAN links.

## 5. DHCP and Addressing Notes

* Workstation IPs in Section 3 are planned/example values for documentation and should not be treated as fixed addresses when clients use DHCP.
* Observed DHCP leases in troubleshooting logs may differ from the example workstation addresses while remaining in the correct subnet and using the correct gateway.
* Record the actual current client address with `ipconfig /all` before running or documenting connectivity tests.
* Do not change a client to a static address solely to match the example table unless the lab configuration specifically requires it.

## 6. Design Notes

* Each /24 LAN provides 254 usable IPv4 addresses.
* Each /30 WAN link provides two usable IPv4 addresses.
* Separate VLAN subnets support departmental segmentation and inter-VLAN routing.
* The current Packet Tracer implementation retains the existing /24 LAN and /30 WAN allocations.
* A separate VLSM exercise was considered as an alternative design; it is not implemented in the current topology.
* Verify documented addresses against Packet Tracer configurations if the topology changes.
